A full-stack Node.js and Express web application that allows users to keep track of all of their important connections as they build their network.

## Project Overview

Journalite is a full-stack web application for users to practice their daily journaling.

## Features

- Create journal entries and save them.
- Retrieve journal entries when wanting to make edits.
- Ability to delete journal entries.
- User-friendly font selection options.

## Installation

1. Clone the repository:

```bash
git clone https://github.com/yourusername/Journalite-App.git
````

2. Navigate to the project directory:

```bash
cd journalite-app
```

3. Install Dependencies:
```bash
npm install
```
4. Start the server:
```bash
npm run dev
```
5. Open your browser and go to:
```bash
http://localhost:9590
```

## Usage

1. Type in the textbox to begin a new journal entry.
2. Select a new font at any moment to change the display text.
3. Save the entry to send it to the archive.
4. Click edit to make changes to the journal entry.
5. Click the 🗑️ trash icon to delete items.
